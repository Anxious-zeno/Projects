This project is a front-end web application which showcases a clock on the desk that can either be viewed in analog or digital mode. In addition, there is a toggle between the two modes, while the digital clock has an animated effect of falling sticky notes when there is an update on minutes or hours. The design has a switch to change between a light and dark mode, and employs soft neumorphism design for the entire interface along with its floating background images. This was made through HTML, CSS, and JavaScript programming languages, and in conjunction with an online tutorial on web development where I learned to use keyframes animation, DOM scripting, and Date object in JavaScript.
