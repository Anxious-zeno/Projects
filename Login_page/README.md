Project Description
It is an authentication front end application that is made up of responsive login and registration forms which are embedded inside a single card. In case there is need for change in view the card flips using CSS 3D transformations. Other functionalities of the project include a light and dark mode option, custom animated glowing border around input field when active, as well as visibility of password through JavaScript and real time validation of matching passwords for registration. The front end application is developed using HTML, CSS, and vanilla JavaScript by following an online guide on web development in order to learn about form animation.
The application requires no local server to function, therefore, it can be run simply by loading up the index HTML page.
